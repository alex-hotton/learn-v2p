# Learn V2P — From Vibecoder to Agent Engineer

A training repo to take you from **Level 1 Vibecoder** all the way up to **Level 3 Agent Engineer**.

Each level lives on its own branch so you can `git checkout` the one you're working on and have a clean, focused starting point.

## Levels

| Level | Branch | What you learn |
|-------|--------|----------------|
| 1 | [`level-1`](../../tree/level-1) | **Vibecoder** — Ship a working app fast with Claude Code. PRD → Supabase MCP → React + Supabase + Tailwind. No fluff. |
| 2 | [`level-2`](../../tree/level-2) | **Equipped Vibecoder** — _Coming soon_ |
| 3 | [`level-3`](../../tree/level-3) | **Agent Engineer** — _Coming soon_ |

## Getting started

Pick your level and check out the branch:

```bash
git clone <this-repo> my-project
cd my-project
git checkout level-1
```

Then follow the README on that branch.
