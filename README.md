# Level 1 — Vibecoder Starter

Go from idea to running app in minutes. Stack is fixed: **Vite + React + TypeScript + Tailwind + Supabase**.

No i18n. No SEO conventions. No 12-folder architecture. Just ship.

## How to use this

1. **Clone this branch as your project:**

   ```bash
   git clone -b level-1 <repo-url> my-app
   cd my-app
   rm -rf .git && git init
   ```

2. **Start Claude Code:**

   ```bash
   claude --dangerously-skip-permissions
   ```

3. **Run the init command:**

   ```
   /initproject
   ```

   Claude will walk you through:
   - Checking your PRD is ready (if not, it'll send you to claude.ai to write one)
   - Connecting the Supabase MCP
   - Scaffolding React + Tailwind + Supabase
   - Building the actual app from your PRD

That's it. No more setup, no more reading docs.

## What's in this template

```
.claude/commands/initproject.md   # The slash command Claude executes

README.md
```

Everything else gets generated by `/initproject`.
